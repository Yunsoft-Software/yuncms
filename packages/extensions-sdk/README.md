# @yunsoft/yuncms-extensions-sdk

Extension authoring helpers for YunCMS endpoints and hooks.

YunCMS is developed and maintained by **[Yunsoft Software](https://yunsoft.com)**.

```js
import { defineEndpoint, defineHook } from '@yunsoft/yuncms-extensions-sdk';
```

See the [extension documentation](https://github.com/Yunsoft-Software/yuncms/blob/main/docs/extensions.md) for manifests, runtime context and service access.

## Project status

YunCMS is under active development, so interfaces and behavior may change between releases. Test extensions against the exact YunCMS release used by the target project.
